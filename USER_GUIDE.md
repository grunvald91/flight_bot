# 🛫 Инструкция по использованию Flight Bot

Полное руководство по поиску и мониторингу авиабилетов.

---

## 📱 Основные способы поиска

### 1️⃣ Быстрый поиск по названиям городов (рекомендуется)

Просто введите названия городов **на русском** в инлайн-режиме:

```
Москва-Стамбул
Санкт-Петербург-Прага
Екатеринбург-Берлин
```

✅ **Бот автоматически найдёт города** —  не нужно знать IATA коды!

---

### 2️⃣ Поиск с датами

Добавьте дату вылета (или туда-обратно):

```
Москва-Стамбул 15.03          → односторонний билет
Москва-Стамбул 15.03-22.03    → туда-обратно
```

**Формат даты**: `ДД.MM` (день и месяц)

---

### 3️⃣ Дешёвые билеты из города

Введите только название города:

```
Москва         → дешёвые билеты из Москвы во ВСЕ города
Берлин         → дешёвые билеты из Берлина
```

---

### 4️⃣ Использование IATA кодов (опционально)

Если хотите, можно использовать коды аэропортов вместо названий:

```
MOW-IST        → Москва-Стамбул (коды)
LED-CDG        → Санкт-Петербург-Париж
```

**Популярные коды**:
- MOW = Москва
- IST = Стамбул  
- CDG = Париж
- LED = Санкт-Петербург
- BER = Берлин
- BCN = Барселона

## 💝 Избранные маршруты

Сохраняйте маршруты, которые вас интересуют, для быстрого доступа.

### Добавление в избранное

**В результатах поиска:**
1. Найдите нужный билет или маршрут
2. Нажмите кнопку **«В избранное»** ⭐

**Из главного меню:**
```
/favorites    → Просмотреть избранное
```

### Быстрый поиск в избранном

В инлайн-режиме введите:

```
@flight_bot избранные
```

Или просто:

```
@flight_bot fav
```

Бот покажет **все сохраненные маршруты с текущими ценами**. Кликните на нужный маршрут и получите актуальные билеты!

### Управление избранным

Из меню **«Избранное»** вы можете:
- 🔍 **Искать билеты** —快速перейти к результатам поиска
- 🔔 **Следить за ценой** — начать мониторинг
- ❌ **Удалить** — удалить из избранного

## 🔔 Слежение за ценой (Подписки)

Автоматическое мониторинг цен на интересующие вас маршруты!

### Быстрый старт

**В результатах поиска:**
1. Нажмите кнопку **«Следить за ценой»** 🔔
2. Готово! Бот будет проверять цены **каждый час**

### Подписка по команде

```
/subscribe Москва-Стамбул
```

Или с английским кодом:

```
/subscribe MOW-IST
```

**Результат**: Бот уведомит вас о **любом снижении цены**

---

## 💰 Установка лимита цены

Получайте уведомления только когда цена упадёт **ниже определённого значения**.

### Команда с лимитом

```
/subscribe Москва-Стамбул 15000
```

**Что это делает:**
- Бот подписывает вас на маршрут Москва → Стамбул
- 🔔 **Уведомление придёт только если цена ≤ 15000₽**
- Цены выше лимита будут игнорироваться

### Примеры лимитов

```
/subscribe Паpиж-Берлин 10000      → Хочу билет дешевле 10000₽
/subscribe LED-ROM 20000            → Из Питера в Рим не дороже 20000₽
/subscribe Москва-Барселона 25000  → В Барселону за 25000 или дешевле
```

## 📊 Как часто проверяются цены?

| Событие | Частота |
|---------|---------|
| ⏰ Проверка подписок | **Каждый час** |
| 🔔 Отправка уведомления | При падении цены или лимит достигнут |

**Пример временной шкалы:**
```
10:00 — Вы подписались на Москва-Ист, цена 18000₽
11:00 — Проверка: цена 17500₽ ↓ → 🔔 Уведомление
12:00 — Проверка: цена 17500₽ (без изменений, без уведомлений)
13:00 — Проверка: цена 16800₽ ↓ → 🔔 Новое уведомление
```

## 🎯 Полный цикл: От поиска к покупке

### Сценарий 1: Одноразовый поиск

```

```

```

2. Кликните на нужный маршрут
3. Посмотрите последние билеты
4. Покупайте!
```

## ❓ Частые вопросы

**Q: Можно ли использовать русские названия городов?**
✅ Да! Это даже рекомендуется. Просто введите: "Москва-Стамбул"

**Q: Что если город с несколькими аэропортами?**
✅ Бот автоматически найдёт основной аэропорт. Если нужен конкретный, используйте IATA код.

**Q: Как часто приходят уведомления?**
✅ Максимум один раз в час при проверке. Если цена не изменилась, уведомления нет.

**Q: Могу ли я иметь несколько подписок на один маршрут?**
❌ Нет, одна подписка на маршрут. Но можно отменить и создать новую.

**Q: Исчезнет ли подписка, если я удалю чат?**
✅ Нет, подписка сохранится в отдельной базе.

**Q: Почему я не вижу все города?**
✅ Бот поддерживает ~4000 городов по всему миру. Если города нет в базе, попробуйте IATA код или более известный аэропорт рядом.
